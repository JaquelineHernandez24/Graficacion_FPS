## 🎯 Objetivo
Desarrollar aplicaciones que permitan crear ambientes de interacción con objetos 3D utilizando controles de FPS (First Person Shooter), mediante el uso del mouse y teclado con los recursos de las librerías de WebGL con Three.js.

## 🚀 Características
- **Control de Cámara:** Implementación de puntero bloqueado (Pointer Lock API) para mirar con el mouse.
- **Movimiento de Personaje:** Sistema de navegación mediante teclas WASD.
- **Física de Colisiones:** Uso de Octree para detección de colisiones precisas entre el jugador y el escenario.
- **Ambiente 3D:** Carga de modelos complejos mediante GLTFLoader.

## 🛠️ Tecnologías utilizadas
- **Three.js:** Motor de gráficos 3D.
- **JavaScript (ES6+):** Lógica de programación y física.
- **HTML5/CSS3:** Estructura y estilos de la interfaz.
- **Git/GitHub:** Control de versiones y despliegue en GitHub Pages.
